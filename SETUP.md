# AI Song Generator - Setup Guide\n\n## Quick Start\n\n### Prerequisites\n- Node.js 18+ installed\n- npm or yarn\n- OpenAI API key (get one at https://platform.openai.com/api-keys)\n\n### Step 1: Clone & Install Backend\n\n```bash\ncd backend\nnpm install\n```\n\n### Step 2: Configure Environment\n\n```bash\ncp .env.example .env\n```\n\nEdit `backend/.env` and add your OpenAI API key:\n\n```\nOPENAI_API_KEY=sk-your-actual-key-here\nPORT=3001\nNODE_ENV=development\nCORS_ORIGIN=http://localhost:5173\n```\n\n### Step 3: Start Backend Server\n\n```bash\n# From the backend directory\nnpm run dev\n```\n\nYou should see:\n```\n🎵 AI Song Generator API running on http://localhost:3001\n   Docs: POST http://localhost:3001/api/lyrics/generate\n```\n\n### Step 4: Install & Start Frontend\n\nIn a **new terminal**:\n\n```bash\ncd frontend\nnpm install\nnpm run dev\n```\n\nYou should see:\n```\n  VITE v5.4.10  ready in 123 ms\n\n  ➜  Local:   http://localhost:5173/\n  ➜  press h to show help\n```\n\n### Step 5: Open the App\n\nOpen your browser and go to:\n```\nhttp://localhost:5173\n```\n\n---\n\n## Troubleshooting\n\n### \"localhost refused to connect\"\n\n**Issue 1: Backend not running**\n- Confirm you're in the `backend` directory\n- Run `npm run dev`\n- Check that you see the \"🎵 AI Song Generator API\" message\n\n**Issue 2: Port already in use**\n```bash\n# Kill process on port 3001 (macOS/Linux)\nlsof -ti:3001 | xargs kill -9\n\n# Or change the port in backend/.env\nPORT=3002\n```\n\n**Issue 3: Missing OpenAI API key**\n- Check `backend/.env` file exists\n- Verify `OPENAI_API_KEY=sk-...` is set\n- Don't use quotes around the key\n- Get a key at https://platform.openai.com/api-keys\n\n**Issue 4: Dependencies not installed**\n```bash\n# Clear node_modules and reinstall\ncd backend\nrm -rf node_modules package-lock.json\nnpm install\n\ncd ../frontend\nrm -rf node_modules package-lock.json\nnpm install\n```\n\n### Frontend won't load\n\n- Make sure backend is running first (check http://localhost:3001/api/health)\n- Clear browser cache or try incognito mode\n- Check browser console for errors (F12 > Console tab)\n- Ensure port 5173 is not in use\n\n### \"Error generating lyrics\"\n\nThis means the API call failed. Check:\n1. Your OpenAI API key is valid\n2. You have API credits available\n3. Backend error logs in terminal\n\n### Still stuck?\n\nCheck the logs:\n\n```bash\n# Backend logs (in backend terminal)\n# You should see incoming requests\n\n# Frontend logs (in browser, press F12)\n# Console tab shows network errors\n\n# Health check\ncurl http://localhost:3001/api/health\n# Should return: {\"status\":\"ok\",\"timestamp\":\"...\"}\n```\n\n---\n\n## File Structure\n\n```\nai-song-generator/\n├── backend/\n│   ├── src/\n│   │   └── index.js          # Express API server\n│   ├── .env.example          # Environment template\n│   └── package.json\n├── frontend/\n│   ├── src/\n│   │   ├── App.jsx           # Main app component\n│   │   ├── components/       # React components\n│   │   │   ├── LyricsGenerator.jsx\n│   │   │   ├── LyricsDisplay.jsx\n│   │   │   ├── VoiceSynthesizer.jsx\n│   │   │   └── SongLibrary.jsx\n│   │   └── index.css         # Global styles\n│   ├── index.html\n│   ├── vite.config.js\n│   └── package.json\n└── README.md\n```\n\n## Development Tips\n\n- **Hot reload**: Both frontend and backend support auto-reload on file changes\n- **API testing**: Use Postman or curl to test endpoints directly\n- **Browser DevTools**: Press F12 to inspect network requests and console\n- **Clear cache**: If changes don't appear, clear browser cache (Ctrl+Shift+Delete)\n\n## Next Steps\n\n1.
